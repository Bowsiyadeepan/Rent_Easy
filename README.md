# RentEasy (Smart Rental Decision Support System)

RentEasy is a comprehensive Android rental decision support platform designed to streamline the rental experience for tenants, property owners, and administrators. Built with a modern MVVM + Repository architecture, RentEasy features an intelligent Smart Rental Score algorithm and Total Cost Estimator to help tenants make data-driven rental decisions, transparent owner listing and request management with atomic transaction handling, and robust admin moderation workflows.

> **Status:** Work in Progress 🚧

## Tech Stack
- **Language & UI:** Kotlin, Jetpack Compose, Material 3, Navigation Compose
- **Architecture:** MVVM + Repository Pattern, Kotlin Coroutines, StateFlow
- **Backend & Cloud Services:** Firebase Authentication, Cloud Firestore, Firebase Cloud Storage
- **Image Loading:** Coil Compose
- **Build System:** Gradle (Version Catalogs `libs.versions.toml`), Android Gradle Plugin 8.7.2, Kotlin 2.0.21
- **Target Platform:** Android (minSdk 24, compileSdk/targetSdk 35, Java 17)
